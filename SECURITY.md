# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Send a report to the
maintainer privately (add your contact address here), with steps to reproduce
and the affected version. You can expect an acknowledgement within a few days.

## Scope

Aeroium loads arbitrary web pages, so the main risks are in how the app
handles navigation, permissions, IPC messages and extensions. Reports about
those areas are especially welcome.
